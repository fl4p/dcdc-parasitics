# Package lead inductance in TO-220/TO-247-class devices

## Abstract

Through-hole power-package inductance is commonly several nH and is topology-specific. Common
source inductance (CSI) is especially important because `L*dI/dt` feeds back into Vgs and changes
switching speed, loss, overshoot, and false-turn-on risk. Board extraction, package completion, and
device-model internal leads must have an explicit boundary so the same path is represented once.

This note is a literature prior and modelling guide. It does **not** provide a bench-derived
correction factor for Fugu2. The retired factors and their failure modes live in the canonical
[SW-ring invalidated-assumption register](../../loss/docs/ring-invalidated-assumptions.md).

## Current Fugu2 package state

- `loss/lib/deck.py:PKG_LEADS["TO-220"]` uses Infineon’s published package-family bin:
  `Ld=2.5`, `Ls=2.0`, `Lg=4.0 nH`. `TO-220-VENDOR` is an exact alias.
- The actual `IPP039N10N5` vendor model publishes `Ls=1.8 nH`; the package-level table does not yet
  express that per-part difference.
- `TO-220-PKGONLY` contains Liu’s package-only midpoints for sensitivity work. It is a floor, not
  the default: it comes from a different device topology and omits exposed lead length.
- Fugu2 uses a copper-only (`lead_mm=0`) board extraction and die-only curve models, so package
  completion is the correct model boundary.
- PCB geometry confirms all Fugu2 TO-220 drains are pin-connected. The horizontal tab-region hole
  is mechanical and has no copper net; a D2PAK tab-path comparison does not apply.
- The damped deck rings lower than the CCM spring bench, but the rail-matched residual is not
  constant. No single lead/L factor is supported, and no such factor is embedded in code.

### Invalidated local assumptions

| Assumption not to reuse | Brief reason |
|---|---|
| The deck lead table is 2.15x, 1.21x, 1.16x, 0.70x, or 2.4–2.7x wrong. | These figures used an undamped deck, mixed vendor/Liu bases, relied on false `C_eff=0.79`, or reduced a rail-dependent residual to one scalar. |
| Liu should replace the vendor default. | Liu is useful package-only sensitivity evidence, but it is a different topology and incomplete path; the final implementation keeps the vendor bin as default and Liu as sensitivity-only. |
| Aikawa’s on-board CSI can fill the package-only slot. | Its PCB fixture is part of the measurement; using it above extracted board copper double-counts that path. |
| Current rating or Rds(on) puts Fugu2 below Liu’s lead inductance. | The paper supports only an in-sample bond-wire trend, not a cross-technology inequality. |
| Fugu2’s horizontal tab carries drain current. | `pcbnew` shows a pin-connected drain and a mechanical, unnetted tab hole. |
| Reducing package L changes avalanche by +36%. | That A/B was undamped and changed switching dynamics in a model already missing its dominant ring loss; the magnitude is not hardware evidence. |

## Definitions

`Package lead inductance` covers conductive paths inside and immediately at the package: exposed
leads, lead frame, die attach/clip or bond wires, and internal die links. It is not board copper.

`Insertion inductance` is the package contribution to a specified power-current loop.

`Common-source inductance` is the source-side path shared by drain-source current and the gate
driver reference:

```text
Vgs_eff = Vgate - Vsource - Lcsi*dIds/dt
```

For cascodes and multi-die devices, a single scalar `Ls` may not preserve the relevant shared
links or mutual signs.

## Published package-scale values

Aikawa et al. measured CSI on PCB fixtures by injecting AC drain-source current and sensing the
source/gate-reference voltage:

```text
Ls = Vac*sin(phi)/(omega*Iac)
```

The fixture is part of the measurement and must keep injection/sense mutual inductance out of the
result.

| package | measured CSI range |
|---|---:|
| TO-247 | 5.5–7.8 nH |
| TO-220 | 3.9–5.7 nH |
| I-PAK | 3.7–4.3 nH |
| D2PAK | 4.9–6.1 nH |
| DPAK | 2.3–3.2 nH |
| SOT-223 | 2.3–2.6 nH |
| SOT-23 | 1.4–1.6 nH |

Roughly one third of TO-220/TO-247 CSI varied within a package family. Destructive inspection
linked much of that spread to source bond-wire count/diameter. A useful rough estimate for `N`
parallel round wires is:

```text
Lbw ~= (mu0*l/(2*pi*N))*(ln(4*l/r) - 3/4)
```

This explains within-family spread; it does not bound an unrelated package from Rds(on) alone.

## Multi-loop package model

Liu et al. extracted a 600 V cascode GaN HEMT TO-220 in Ansoft Q3D and verified it by double-pulse
testing. Its value here is the decomposed topology, not a claim that the numbers match Fugu2.

| element | turn-on | turn-off |
|---|---:|---:|
| internal `Lint1` | 0.27 nH | 0.26 nH |
| internal `Lint2` | 0.23 nH | 0.17 nH |
| internal `Lint3` | 0.24 nH | 0.43 nH |
| source lead `Ls` | 0.57 nH | 0.89 nH |
| gate lead `Lg` | 2.87 nH | 3.12 nH |
| drain lead `Ld` | 1.89 nH | 1.62 nH |

Removing `Ls`, `Lint1`, or `Lint3` changed simulated turn-on energy more than removing the larger
`Lg` or `Ld` terms. Sensitivity follows shared-path topology, not only inductance magnitude.

Their loop totals also show package scale:

| term | DPT fixture | buck fixture |
|---|---:|---:|
| PCB loop | 3.6 nH | 1.6 nH |
| input-cap package | 0.3 nH | 0.3 nH |
| HEMT package | 3.0 nH | 3.0 nH |
| diode package | 1.8 nH | 1.8 nH |
| current shunt package | 2.0 nH | — |
| total | 10.7 nH | 6.7 nH |

## Ring-derived extraction

The common ring inversion is:

```text
L ~= 1/((2*pi*f)^2*C)
```

It measures the effective L resonating with the effective capacitance in that transient. Before
allocating the result, check:

- edge identity and hard-switch/ZVS state;
- nonlinear Coss definition and rail calibration;
- package leads already inside the device model;
- external leads and board extraction terminals;
- current shunts, probe grounds, and fixture paths;
- coupling signs and circulating modes;
- damping and modal-fit trust.

A ring is a total-loop cross-check, not a sole calibration of one package term.

## Design implications

CSI is a switching-loss and control-loop term. TI SLPA009 shows how high-side CSI reduces effective
gate drive during hard switching. Kelvin-source and integrated power-stage packages can remove
most package source inductance from the gate reference even when the power loop still contains a
source-side path.

Dymond and Stark demonstrated a 17% inferred loop-L reduction for one TO-220 Schottky-diode
fixture using nearby conductive surfaces and image currents. It did not establish a general
MOSFET CSI correction. Treat nearby metal as an electromagnetic part, and validate it in the
actual geometry.

## Guidance

- State whether extraction terminals are pad, pin, or die plane.
- Record whether a SPICE model already contains package leads.
- Preserve Ld, Ls/CSI, Lg, internal links, and relevant mutuals when topology matters.
- Prefer per-part measurements/extractions to hidden-geometry guesses.
- Compare an on-board CSI measurement against `board CSI + package Ls`, not package Ls alone.
- Read the invalidated-assumption register before deriving a Fugu2 lead correction from existing
  ring data.
